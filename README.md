# 🎓 Santi's Computer Science Project Collection

Welcome to a collection of my projects developed throughout my Computer Science journey at **Silliman University**. This repository showcases various academic and personal projects that reflect my growth in web development, systems programming, and software design.

## 📁 Projects

### 🗳️ SUSG Voting System
A web-based voting system developed for **Silliman University Student Government** elections.  
**Tech Stack:** HTML, CSS, JavaScript, PHP  
- Allows students to securely cast votes online  
- Includes candidate display, ballot casting, and vote tallying  
- Focused on user-friendly design and secure functionality

---

### 🖥️ CPU Scheduling Simulator
A desktop simulator created for our **Operating Systems** course.  
**Tech Stack:** Java (or specify language if different)  
- Simulates common CPU scheduling algorithms like:
  - First-Come, First-Served (FCFS)
  - Shortest Job Next (SJN)
  - Round Robin
- Designed to visualize how different algorithms affect process execution and turnaround time

---

### 🎮 Warframe Market Finder
A utility application built for the online game **Warframe**, using community market APIs.  
**Tech Stack:** Python, Tkinter  
- Fetches item prices and availability from the Warframe Market API  
- Allows players to search for the best deals for in-game items  
- Built with a simple and functional GUI for quick lookup
